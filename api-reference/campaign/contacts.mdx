# Update Campaign Contacts

Add or update contacts for a specific campaign. This endpoint allows you to manage the target audience for your campaigns by adding new contacts or updating existing ones.

## Overview

The Update Campaign Contacts endpoint enables you to:

- **Add New Contacts**: Include additional contacts in your campaign
- **Update Contact Information**: Modify existing contact details
- **Bulk Contact Management**: Add multiple contacts at once
- **Contact Validation**: Ensure contact data is valid before adding
- **Duplicate Prevention**: Avoid adding duplicate contacts

## Contact Management

### Adding Contacts
Add new contacts to your campaign with their details:

<Steps>
<Step title="Prepare Contact Data">
  Gather contact information including phone numbers and attributes.
</Step>

<Step title="Validate Phone Numbers">
  Ensure phone numbers are in the correct format and valid.
</Step>

<Step title="Add Attributes">
  Include any custom attributes for personalization.
</Step>

<Step title="Submit to Campaign">
  Send contact data to the campaign endpoint.
</Step>

<Step title="Verify Addition">
  Confirm contacts were added successfully.
</Step>
</Steps>

### Contact Validation
All contacts must meet these requirements:

- **Valid Phone Number**: Must have a valid `sys_phone` field
- **Unique Phone Numbers**: No duplicate phone numbers in the same campaign
- **Proper Format**: Phone numbers are automatically cleaned to digits only
- **Required Fields**: `sys_phone` is the only required field

## Examples

### Add Single Contact

<RequestExample>
```bash cURL
curl -X POST 'https://api.example.com/v2/campaign/12345/contacts' \
  -H 'Content-Type: application/json' \
  -H 'xi-api-key: YOUR_API_KEY' \
  -d '{
    "contacts": [
      {
        "sys_phone": "+1234567890",
        "first_name": "John",
        "last_name": "Doe",
        "email": "john@example.com",
        "company": "Acme Corp"
      }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json Success Response
{
  "currentCampaignStatus": "updated",
  "message": "Campaign contacts updated successfully",
  "contactsAdded": 1,
  "totalContacts": 1501
}
```
</ResponseExample>

## Contact Data Structure

### Required Fields
- **sys_phone**: Contact's phone number (required)

### Optional Fields
You can include any additional attributes:

```json
{
  "sys_phone": "+1234567890",
  "first_name": "John",
  "last_name": "Doe",
  "email": "john@example.com",
  "company": "Acme Corp",
  "industry": "Technology",
  "preferred_language": "en",
  "customer_tier": "premium",
  "last_purchase": "2024-01-15",
  "custom_field": "custom_value"
}
```

### Phone Number Formatting
Phone numbers are automatically cleaned:

- **Input**: `+1 (234) 567-8900`
- **Cleaned**: `12345678900`
- **Stored**: `12345678900`

<Warning>
**Phone Validation**: Ensure phone numbers are valid and reachable to avoid campaign failures.
</Warning>

## Error Handling

<AccordionGroup>
<Accordion title="Invalid Phone Numbers">
  - **Error**: `400 Bad Request - Invalid phone number format`
  - **Cause**: Phone numbers that can't be cleaned or validated
  - **Solution**: Ensure phone numbers are in international format
</Accordion>

<Accordion title="Duplicate Phone Numbers">
  - **Error**: `400 Bad Request - Duplicate sys_phone found`
  - **Cause**: Multiple contacts with the same phone number
  - **Solution**: Remove duplicates before adding or use update operations
</Accordion>

<Accordion title="Campaign Not Found">
  - **Error**: `404 Not Found`
  - **Cause**: Campaign ID doesn't exist or user doesn't have access
  - **Solution**: Verify the campaign ID and ensure you have proper permissions
</Accordion>

<Accordion title="No Valid Contacts">
  - **Error**: `400 Bad Request - No Contacts with a valid sys_phone found`
  - **Cause**: All contacts in the request have invalid phone numbers
  - **Solution**: Ensure at least one contact has a valid phone number
</Accordion>
</AccordionGroup>
