# Get Campaign

Retrieve comprehensive details about a specific campaign including its configuration, status, performance metrics, and associated data.

## Overview

The Get Campaign endpoint provides detailed information about a campaign, including:

- **Campaign Configuration**: All campaign settings and parameters
- **Current Status**: Real-time campaign status and progress
- **Performance Metrics**: Delivery rates, response rates, and engagement data
- **Contact Information**: Details about the target audience
- **Scheduling Details**: Start/end times, timezone, and execution schedule

## Response Fields

### Campaign Information
- **id**: Unique campaign identifier
- **name**: Campaign name
- **type**: Campaign type (phone, sms, whatsapp)
- **status**: Current campaign status
- **bot_id**: Associated bot identifier
- **created_at**: Campaign creation timestamp
- **updated_at**: Last modification timestamp

### Scheduling Information
- **start_date**: Campaign start date
- **end_date**: Campaign end date
- **start_time**: Daily start time
- **end_time**: Daily end time
- **timezone**: Campaign timezone
- **days**: Days of the week when campaign runs

### Performance Metrics
- **total_contacts**: Number of contacts in the campaign
- **messages_sent**: Number of messages sent
- **delivery_rate**: Percentage of messages successfully delivered
- **response_rate**: Percentage of contacts who responded
- **conversion_rate**: Percentage of contacts who completed desired actions

## Campaign Status Values

| Status | Code | Description |
|--------|------|-------------|
| Active | 1 | Campaign is currently running |
| Paused | 2 | Campaign is temporarily stopped |
| Completed | 3 | Campaign has finished successfully |
| Cancelled | -1 | Campaign was cancelled before completion |
| Failed | -2 | Campaign encountered errors during execution |
| Archived | -3 | Campaign has been archived |

## Error Handling

<AccordionGroup>
<Accordion title="Campaign Not Found">
  - **Error**: `404 Not Found`
  - **Cause**: Campaign ID doesn't exist or user doesn't have access
  - **Solution**: Verify the campaign ID and ensure you have proper permissions
</Accordion>

<Accordion title="Invalid Campaign ID">
  - **Error**: `400 Bad Request`
  - **Cause**: Campaign ID is not a valid number
  - **Solution**: Ensure the campaign ID is a valid integer
</Accordion>

<Accordion title="Access Denied">
  - **Error**: `403 Forbidden`
  - **Cause**: User doesn't have permission to access this campaign
  - **Solution**: Contact administrator for proper access permissions
</Accordion>
</AccordionGroup>
