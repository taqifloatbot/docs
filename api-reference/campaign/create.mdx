# Create Campaign V2

Create a new marketing campaign with advanced scheduling, timezone support, and multi-channel capabilities. This endpoint supports phone, SMS, and WhatsApp campaigns with intelligent scheduling.

## Overview

The Create Campaign V2 endpoint allows you to set up sophisticated marketing campaigns with:

- **Multi-channel support** (phone, SMS, WhatsApp)
- **Advanced scheduling** with timezone awareness
- **Flexible contact targeting** using contact lists
- **Custom attributes** for personalized messaging
- **Intelligent bot integration** for interactive campaigns

## Key Features

### Advanced Scheduling
- **Timezone Support**: Schedule campaigns in any timezone for global reach
- **Recurring Campaigns**: Set up campaigns that run on specific days of the week
- **Time-based Execution**: Define precise start and end times for optimal engagement
- **Date Range**: Set campaign duration with flexible start and end dates

### Multi-Channel Configuration
- **Channel-specific Settings**: Optimize configurations for each channel type
- **Template Management**: Use pre-approved templates for WhatsApp campaigns
- **Bot Integration**: Connect intelligent bots for interactive conversations
- **Media Support**: Include images, videos, and documents in campaigns

## Campaign Scheduling

### Timezone Support
When using timezone-aware scheduling, the system automatically converts your local times to UTC:

<Steps>
<Step title="Set Local Time">
  Specify your campaign time in the local timezone of your target audience.
</Step>

<Step title="Timezone Conversion">
  The system converts local times to UTC for consistent execution.
</Step>

<Step title="Day Mapping">
  Local days are mapped to UTC days to ensure campaigns run on the correct days.
</Step>

<Step title="Execution">
  Campaigns execute at the correct local time for each contact.
</Step>
</Steps>

### Example: Global Campaign
```json
{
  "timezone": "America/New_York",
  "start_time": "09:00:00",
  "end_time": "17:00:00",
  "days": [1, 2, 3, 4, 5],
  "start_date": "2024-06-01",
  "end_date": "2024-06-30"
}
```

This creates a campaign that runs Monday-Friday, 9 AM - 5 PM Eastern Time.

## Error Handling

<AccordionGroup>
<Accordion title="Invalid Campaign Parameters">
  - **Error**: `400 Bad Request`
  - **Cause**: Missing required fields or invalid data types
  - **Solution**: Verify all required fields are provided and data types match the schema
</Accordion>

<Accordion title="Invalid Bot ID">
  - **Error**: `400 Bad Request - Invalid bot ID`
  - **Cause**: Bot ID doesn't exist or user doesn't have access
  - **Solution**: Verify the bot ID and ensure you have proper permissions
</Accordion>

<Accordion title="Invalid Contact Lists">
  - **Error**: `400 Bad Request - Invalid list IDs`
  - **Cause**: One or more contact list IDs don't exist
  - **Solution**: Verify all list IDs exist and are accessible
</Accordion>

<Accordion title="WhatsApp Channel Not Configured">
  - **Error**: `400 Bad Request - Please configure whatsapp channel`
  - **Cause**: WhatsApp Business API not set up for the user
  - **Solution**: Configure WhatsApp Business API before creating WhatsApp campaigns
</Accordion>
</AccordionGroup>
