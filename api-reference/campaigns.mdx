# Campaigns API

The Campaigns API provides endpoints for creating, managing, and monitoring marketing campaigns across multiple channels including phone, SMS, and WhatsApp.

## Overview

Campaigns are the core of the marketing automation platform, allowing you to:

- **Create targeted campaigns** with specific audiences and scheduling
- **Support multiple channels** (phone, SMS, WhatsApp) from a single campaign
- **Schedule campaigns** with timezone support for global reach
- **Monitor performance** with detailed analytics and reporting
- **Manage campaign lifecycle** from creation to completion

## Key Features

### Advanced Scheduling
- **Timezone Support**: Schedule campaigns in any timezone
- **Recurring Campaigns**: Set up campaigns that run on specific days
- **Time-based Execution**: Define precise start and end times
- **Date Range**: Set campaign duration with start and end dates

### Multi-Channel Support
- **Unified Interface**: Manage all channels from a single API
- **Channel-specific Configuration**: Optimize settings for each channel type
- **Cross-channel Analytics**: Track performance across all channels

### Contact Management
- **Dynamic Contact Lists**: Add or remove contacts from campaigns
- **Contact Attributes**: Store and use custom contact information
- **Bulk Operations**: Manage large contact lists efficiently

## Campaign Status

Campaigns can have the following statuses:

| Status | Code | Description |
|--------|------|-------------|
| Active | 1 | Campaign is running and executing |
| Paused | 2 | Campaign is temporarily stopped |
| Completed | 3 | Campaign has finished successfully |
| Cancelled | -1 | Campaign was cancelled before completion |
| Failed | -2 | Campaign encountered errors during execution |
| Archived | -3 | Campaign has been archived |

## Best Practices

<Tip>
**Campaign Planning**: Always test your campaigns with a small audience before full deployment.
</Tip>

<Warning>

## Error Handling

Common error scenarios and solutions:

<AccordionGroup>
<Accordion title="Invalid Campaign Parameters">
  - **Error**: `400 Bad Request`
  - **Cause**: Missing required fields or invalid data types
  - **Solution**: Verify all required fields are provided and data types match the schema
</Accordion>

<Accordion title="Authentication Issues">
  - **Error**: `401 Unauthorized`
  - **Cause**: Invalid or missing API key
  - **Solution**: Check your API key and ensure it's included in the request header
</Accordion>

<Accordion title="Rate Limit Exceeded">
  - **Error**: `429 Too Many Requests`
  - **Cause**: Exceeded API rate limits
  - **Solution**: Implement exponential backoff and respect rate limit headers
</Accordion>
</AccordionGroup>
