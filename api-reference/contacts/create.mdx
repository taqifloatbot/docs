# Create Contact List

Create a new contact list and add contacts to it. This endpoint allows you to organize your contacts into targeted lists for campaign management.

## Overview

The Create Contact List endpoint enables you to:

- **Create New Lists**: Set up new contact lists with descriptive names
- **Add Contacts**: Include contacts with their details and attributes
- **Bulk Operations**: Add multiple contacts at once
- **Custom Attributes**: Store additional contact information for personalization
- **List Organization**: Organize contacts for better campaign management

## Contact List Creation

### List Setup
Create contact lists to organize your audience:

<Steps>
<Step title="Choose List Name">
  Select a descriptive name that clearly indicates the list's purpose.
</Step>

<Step title="Prepare Contacts">
  Gather contact information including phone numbers and attributes.
</Step>

<Step title="Validate Data">
  Ensure all contact data is valid and properly formatted.
</Step>

<Step title="Create List">
  Submit the list creation request with contact data.
</Step>

<Step title="Verify Creation">
  Confirm the list was created successfully.
</Step>
</Steps>

### Contact Requirements
All contacts must meet these requirements:

- **Valid Phone Number**: Must have a valid `sys_phone` field
- **Unique Phone Numbers**: No duplicate phone numbers in the same list
- **Proper Format**: Phone numbers are automatically cleaned to digits only
- **Required Fields**: `sys_phone` is the only required field

## Examples

### Create List with Single Contact

<RequestExample>
```bash cURL
curl -X POST 'https://api.example.com/v2/campaign/contacts' \
  -H 'Content-Type: application/json' \
  -H 'xi-api-key: YOUR_API_KEY' \
  -d '{
    "listName": "VIP Customers",
    "contacts": [
      {
        "sys_phone": "+1234567890",
        "first_name": "John",
        "last_name": "Doe",
        "email": "john@example.com",
        "company": "Acme Corp",
        "customer_tier": "premium"
      }
    ]
  }'
```
</RequestExample>

<ResponseExample>
```json Success Response
{

  "message": "Contact list created successfully",
  "contactsAdded": 1,
  "totalContacts": 1
}
```

</ResponseExample>

## Contact Data Structure

### Required Fields
- **listName**: Name for the contact list
- **contacts**: Array of contact objects
- **sys_phone**: Contact's phone number (required for each contact)

### Optional Fields
You can include any additional attributes for each contact:

```json
{
  "sys_phone": "+1234567890",
  "first_name": "John",
  "last_name": "Doe",
  "email": "john@example.com",
  "company": "Acme Corp",
  "industry": "Technology",
  "preferred_language": "en",
  "customer_tier": "premium",
  "last_purchase": "2024-01-15",
  "custom_field": "custom_value"
}
```

### Phone Number Formatting
Phone numbers are automatically cleaned:

- **Input**: `+1 (234) 567-8900`
- **Cleaned**: `12345678900`
- **Stored**: `12345678900`

<Warning>
**Phone Validation**: Ensure phone numbers are valid and reachable to avoid campaign failures.
</Warning>

## Error Handling

<AccordionGroup>
<Accordion title="Missing List Name">
  - **Error**: `400 Bad Request - List name required`
  - **Cause**: No list name provided in the request
  - **Solution**: Include a listName field in your request
</Accordion>

<Accordion title="Invalid Phone Numbers">
  - **Error**: `400 Bad Request - No Contacts with a valid sys_phone found`
  - **Cause**: All contacts have invalid phone numbers
  - **Solution**: Ensure at least one contact has a valid phone number
</Accordion>

<Accordion title="Duplicate Phone Numbers">
  - **Error**: `400 Bad Request - Contacts have duplicate sys_phone`
  - **Cause**: Multiple contacts with the same phone number
  - **Solution**: Remove duplicate phone numbers before creating the list
</Accordion>

<Accordion title="Empty Contact List">
  - **Error**: `400 Bad Request - No Contacts with a valid sys_phone found`
  - **Cause**: No valid contacts provided
  - **Solution**: Ensure at least one contact has a valid phone number
</Accordion>
</AccordionGroup>
