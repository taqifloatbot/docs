# Update Contact List

Update the name and metadata of a contact list. This endpoint allows you to modify list information while preserving all contact data and relationships.

## Overview

The Update Contact List endpoint enables you to:

- **Rename Lists**: Change the name of existing contact lists
- **Update Metadata**: Modify list information and descriptions
- **Maintain Relationships**: Preserve all contact data and campaign associations
- **List Organization**: Keep your contact lists organized and up-to-date
- **Data Integrity**: Ensure all list data remains intact during updates

## Examples

### Update List Name

<RequestExample>
```bash cURL
curl -X POST 'https://api.example.com/v2/campaign/contacts/123' \
  -H 'Content-Type: application/json' \
  -H 'xi-api-key: YOUR_API_KEY' \
  -d '{
    "list_name": "Premium VIP Customers"
  }'
```
</RequestExample>

<ResponseExample>
```json Success Response
{
  "status": "success",
  "message": "Contact list updated successfully"
}
```
</ResponseExample>

## Request Parameters

### Required Fields
- **list_name**: New name for the contact list (3-200 characters)

### Validation Rules
- **Minimum Length**: 3 characters
- **Maximum Length**: 200 characters
- **Character Restrictions**: Alphanumeric characters, spaces, and common punctuation
- **Uniqueness**: List names should be unique within your account

## Error Handling

<AccordionGroup>
<Accordion title="List Not Found">
  - **Error**: `404 Not Found`
  - **Cause**: Contact list ID doesn't exist or user doesn't have access
  - **Solution**: Verify the list ID and ensure you have proper permissions
</Accordion>

<Accordion title="Invalid List Name">
  - **Error**: `400 Bad Request - Invalid list name`
  - **Cause**: List name doesn't meet validation requirements
  - **Solution**: Ensure list name is 3-200 characters and follows naming rules
</Accordion>

<Accordion title="Duplicate List Name">
  - **Error**: `400 Bad Request - List name already exists`
  - **Cause**: Another list with the same name already exists
  - **Solution**: Choose a unique name for the list
</Accordion>

<Accordion title="Access Denied">
  - **Error**: `403 Forbidden`
  - **Cause**: User doesn't have permission to update this list
  - **Solution**: Contact administrator for proper access permissions
</Accordion>
</AccordionGroup>
