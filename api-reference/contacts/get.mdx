# Get Contacts of List

Retrieve all contacts from a specific contact list. This endpoint provides detailed information about each contact including their attributes and metadata.

## Overview

The Get Contacts of List endpoint allows you to:

- **View Contact Details**: See all contacts in a specific list
- **Access Attributes**: Retrieve custom attributes for each contact
- **Contact Management**: Understand the composition of your contact lists
- **Data Export**: Get contact data for analysis or export
- **List Validation**: Verify list contents and data quality

## Response Fields

### Contact Information
- **id**: Unique identifier for the contact
- **sys_phone**: Contact's phone number (cleaned to digits only)
- **attributes**: Object containing all custom contact attributes
- **date_added**: When the contact was added to the list

### Contact Attributes
The `attributes` object can contain any custom fields:

- **Standard Fields**: first_name, last_name, email, company
- **Custom Fields**: Any additional attributes you've added
- **Metadata**: Lead scores, preferences, notes, etc.
- **Behavioral Data**: Engagement history, purchase history, etc.

## Error Handling

<AccordionGroup>
<Accordion title="List Not Found">
  - **Error**: `404 Not Found`
  - **Cause**: Contact list ID doesn't exist or user doesn't have access
  - **Solution**: Verify the list ID and ensure you have proper permissions
</Accordion>

<Accordion title="Invalid List ID">
  - **Error**: `400 Bad Request`
  - **Cause**: List ID is not a valid number
  - **Solution**: Ensure the list ID is a valid integer
</Accordion>

<Accordion title="Access Denied">
  - **Error**: `403 Forbidden`
  - **Cause**: User doesn't have permission to access this list
  - **Solution**: Contact administrator for proper access permissions
</Accordion>

<Accordion title="List Archived">
  - **Error**: `404 Not Found`
  - **Cause**: Contact list has been archived
  - **Solution**: Use an active contact list or restore the archived list
</Accordion>
</AccordionGroup>

## Contact Data Analysis

### Attribute Analysis
```javascript
// Analyze contact attributes
const contacts = await getContactsFromList(123);
const analysis = {
  totalContacts: contacts.length,
  attributes: {},
  segments: {}
};

// Count attribute usage
contacts.forEach(contact => {
  Object.keys(contact.attributes).forEach(attr => {
    analysis.attributes[attr] = (analysis.attributes[attr] || 0) + 1;
  });
});

// Segment by customer tier
contacts.forEach(contact => {
  const tier = contact.attributes.customer_tier || 'unknown';
  analysis.segments[tier] = (analysis.segments[tier] || 0) + 1;
});
```

### Data Quality Check
```python
import requests

# Get contacts and check data quality
response = requests.get(
    'https://api.example.com/v2/campaign/contacts/123',
    headers={'xi-api-key': 'YOUR_API_KEY'}
)
contacts = response.json()

# Check data quality
quality_issues = []
for contact in contacts:
    if not contact.get('attributes', {}).get('email'):
        quality_issues.append(f"Missing email for {contact['sys_phone']}")
    if not contact.get('attributes', {}).get('first_name'):
        quality_issues.append(f"Missing first name for {contact['sys_phone']}")

print(f"Data quality issues: {len(quality_issues)}")
```

### Data Export
```python
import csv
import requests

# Export contacts to CSV
response = requests.get(
    'https://api.example.com/v2/campaign/contacts/123',
    headers={'xi-api-key': 'YOUR_API_KEY'}
)
contacts = response.json()

# Write to CSV
with open('contacts.csv', 'w', newline='') as csvfile:
    writer = csv.writer(csvfile)
    writer.writerow(['Phone', 'First Name', 'Last Name', 'Email', 'Company'])
    
    for contact in contacts:
        attrs = contact.get('attributes', {})
        writer.writerow([
            contact['sys_phone'],
            attrs.get('first_name', ''),
            attrs.get('last_name', ''),
            attrs.get('email', ''),
            attrs.get('company', '')
        ])
```
