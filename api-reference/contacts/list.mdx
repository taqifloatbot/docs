# Get Contact Lists

Retrieve all contact lists associated with your account. This endpoint provides a comprehensive view of your contact organization and management capabilities.

## Overview

The Get Contact Lists endpoint allows you to:

- **View All Lists**: See all contact lists in your account
- **List Information**: Get details about each list including size and creation date
- **List Management**: Understand your contact organization structure
- **Campaign Planning**: Identify which lists to use for campaigns

## Response Fields

### Contact List Information
- **id**: Unique identifier for the contact list
- **list_name**: Name of the contact list
- **created_at**: When the list was created
- **contact_count**: Number of contacts in the list
- **last_updated**: When the list was last modified

### List Metadata
- **Creation Date**: When the list was originally created
- **Last Updated**: Most recent modification timestamp
- **Contact Count**: Current number of contacts in the list
- **List Status**: Whether the list is active or archived

## Integration Examples

### Dashboard Integration
```javascript
// Fetch contact lists for dashboard display
const response = await fetch('/v2/campaign/contacts', {
  headers: {
    'xi-api-key': 'YOUR_API_KEY'
  }
});
const lists = await response.json();

// Display lists in dashboard
lists.forEach(list => {
  console.log(`${list.list_name}: ${list.contact_count} contacts`);
});
```

### Campaign Planning
```python
import requests

# Get contact lists for campaign planning
response = requests.get(
    'https://api.example.com/v2/campaign/contacts',
    headers={'xi-api-key': 'YOUR_API_KEY'}
)
lists = response.json()

# Find the best list for campaign
best_list = max(lists, key=lambda x: x['contact_count'])
print(f"Best list for campaign: {best_list['list_name']}")
```
