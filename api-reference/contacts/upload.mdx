# Upload Contact List (CSV)

Upload a CSV file to create a new contact list with bulk contact data. This endpoint allows you to import large numbers of contacts efficiently using a standardized CSV format.

## Overview

The Upload Contact List (CSV) endpoint enables you to:

- **Bulk Import**: Import large numbers of contacts at once
- **CSV Processing**: Automatically process CSV files with contact data
- **Data Validation**: Validate contact data during import
- **Error Handling**: Handle import errors gracefully
- **Progress Tracking**: Monitor import progress and results

## CSV Format Requirements

### Required Columns
- **sys_phone**: Contact's phone number (required for each row)

### Optional Columns
You can include any additional columns for contact attributes:

```csv
sys_phone,first_name,last_name,email,company,industry,customer_tier
+1234567890,John,Doe,john@example.com,Acme Corp,Technology,premium
+1987654321,Jane,Smith,jane@example.com,Tech Inc,Finance,standard
+1555123456,Bob,Johnson,bob@example.com,Startup Co,Healthcare,basic
```

### CSV Formatting
- **Headers**: First row should contain column headers
- **Encoding**: UTF-8 encoding recommended
- **Delimiter**: Comma-separated values
- **Quotes**: Use quotes for values containing commas
- **Line Endings**: Standard line endings (CRLF or LF)

## Error Handling

<AccordionGroup>
<Accordion title="Invalid CSV Format">
  - **Error**: `400 Bad Request - CSV Parse error`
  - **Cause**: CSV file is not properly formatted or readable
  - **Solution**: Ensure CSV file is properly formatted with correct headers and data
</Accordion>

<Accordion title="Missing Required Column">
  - **Error**: `400 Bad Request - Missing sys_phone column`
  - **Cause**: CSV file doesn't contain the required sys_phone column
  - **Solution**: Add sys_phone column to your CSV file
</Accordion>

<Accordion title="No Valid Contacts">
  - **Error**: `400 Bad Request - No Contacts with a valid sys_phone found`
  - **Cause**: All contacts in the CSV have invalid phone numbers
  - **Solution**: Ensure at least one contact has a valid phone number
</Accordion>

<Accordion title="File Too Large">
  - **Error**: `400 Bad Request - File too large`
  - **Cause**: CSV file exceeds size limits
  - **Solution**: Split the file into smaller chunks or compress the file
</Accordion>
</AccordionGroup>

## Integration Examples

### Python Upload Script
```python
import requests
import csv

# Prepare CSV data
contacts = [
    {"sys_phone": "+1234567890", "first_name": "John", "last_name": "Doe"},
    {"sys_phone": "+1987654321", "first_name": "Jane", "last_name": "Smith"}
]

# Write to CSV
with open('contacts.csv', 'w', newline='') as csvfile:
    writer = csv.DictWriter(csvfile, fieldnames=['sys_phone', 'first_name', 'last_name'])
    writer.writeheader()
    writer.writerows(contacts)

# Upload CSV
with open('contacts.csv', 'rb') as f:
    files = {'file': f}
    data = {'list_name': 'Python Import'}
    response = requests.post(
        'https://api.example.com/v2/campaign/contacts/upload',
        headers={'xi-api-key': 'YOUR_API_KEY'},
        files=files,
        data=data
    )
    print(response.json())
```
